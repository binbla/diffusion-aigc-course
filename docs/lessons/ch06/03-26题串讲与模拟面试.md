# 6.3 26 题串讲与模拟面试

> **所属章节**：第 6 章 评估、失败模式与面试实战  
> **课时**：90 分钟  
> **前置**：第 1–5 章  
> **对应面试题**：全部 26 题  
> **一句话目标**：把“会知识点”变成“能在压力下讲清楚”，并完成一次可评分的模拟面试。

---

## 1. 学习目标

学完本节，你应该能够：

1. 用固定结构回答任意高频题；
2. 按 6 组串起 26 题；
3. 接住至少两层追问；
4. 在白板上写核心公式；
5. 完成 15/45 分钟模拟面试；
6. 用评分表做自我复盘。

---

## 2. 90 秒答题模板

### 2.1 四步结构

1. **一句话结论**：它是什么/解决什么；
2. **核心原理**：1 个公式/结构/流程；
3. **对比/取舍**：和相近方法比；
4. **局限/实践**：代价、失败模式、使用场景。

### 2.2 示例：DDPM/DDIM

> 一句话：共享训练目标，区别在反向。
> 原理：DDIM 非马尔可夫、可确定性、可跳步。
> 对比：DDPM 随机/多样，DDIM 快/可反演。
> 局限：极低步数丢细节，确定性降多样性。

### 2.3 避免

- 一上来讲细节，没有结论；
- 只背名词，没有公式/图；
- 不会时硬编；
- 超过 2 分钟。

## 3. 26 题分组

### 组 A：扩散基础（D5、D9、D10、A3）

关键词：

- 前向/后验/ELBO；
- 噪声预测；
- SNR/schedule；
- 重参数化。

### 组 B：采样与加速（D1、D3、D4、D8）

关键词：

- DDIM；
- DPM-Solver；
- LCM/Turbo；
- CFG。

### 组 C：SD 系统（A2、A5、A6、A8、A16、D7）

关键词：

- VAE/VQ；
- latent diffusion；
- cross-attention；
- 两阶段训练；
- Offset Noise。

### 组 D：条件与个性化（A1、A12、A13、A14、A15）

关键词：

- CLIP；
- ControlNet；
- IP-Adapter；
- LoRA/DreamBooth/TI。

### 组 E：演进与对比（A7、A10、A11、D6）

关键词：

- SDXL；
- SD3/MMDiT/Flow；
- LDM vs unCLIP；
- GAN vs Diffusion。

### 组 F：评估与失败（A4、A9、D2）

关键词：

- FID/CLIPScore；
- 模式坍塌；
- 非高斯扩散。

| 题号 | 一句话钩子 |

| A1 | CLIP 双塔 + 对称 InfoNCE |
| A2 | AE 确定、VAE 连续、VQ 离散 |
| A3 | 随机性剥离到 ε |
| A4 | FID 保真、CLIPScore 对齐、人工偏好 |
| A5 | SD 核心 = Latent Diffusion |
| A6 | 两阶段：VAE + LDM |
| A7 | SD=LDM，DALL·E 2=unCLIP |
| A8 | 图像 Q，文本 K/V |
| A9 | 坍塌 = 覆盖少数模式 |
| A10 | SDXL = 双文本 + micro-cond + refiner |
| A11 | SD3 = MMDiT + Flow + T5 + 16ch VAE |

## 8. 评分表

每项 1–5：

| 维度 | 1 分 | 5 分 |
|---|---|---|
| 正确性 | 明显错误 | 公式/概念准确 |
| 结构 | 散乱 | 结论→原理→对比→局限 |
| 深度 | 只会背 | 能接两层追问 |
| 表达 | 冗长/卡壳 | 简洁有逻辑 |
| 诚实 | 硬编 | 不会时承认并推理 |

总分 25；≥ 18 通过，≥ 21 优秀。

---

## 9. 常见失败模式

1. 把 DDIM、DPM-Solver、LCM 混为一谈；
2. CFG 说成需要分类器；
3. SD 说成像素扩散；
4. ControlNet 说成训练整个 SD；
5. IP-Adapter 和 ControlNet 混；
6. FID 当唯一指标；
7. 项目只讲“用了什么”，不讲取舍；
8. 不会时硬编。

---

## 10. 练习方法

1. 每天 5 题，90 秒录音；
2. 每周一次 15 分钟模拟；
3. 错题回到对应章节；
4. 白板写核心 10 题；
5. 最后做一次 45 分钟全真模拟。
