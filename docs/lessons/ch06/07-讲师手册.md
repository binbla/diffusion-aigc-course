# 第 6 章讲师手册

> 用途：把第 6 章 3 节课讲顺，并组织一次模拟面试。  
> 原则：**讲指标边界、诊断逻辑和表达，不做评测工程。**

---

## 1. 授课对象与前置

**对象**：

- 已学完第 1–5 章；
- 需要把知识转成面试表达；
- 准备模拟面试。

**前置**：

- DDPM/采样/SD/CLIP/ControlNet 基础；
- 知道 FID/CLIPScore 的名字（不熟也没关系）。

**不需要**：

- 跑过 FID；
- 训练过 GAN；
- 搭过评测平台。

## 3. 第 1 课：评估指标

### 3.1 时间安排（90 分钟）

| 时间 | 环节 | 内容 |
|---|---|---|
| 0–5 | 开场 | 为什么评估难 |
| 5–25 | 四维度 | 保真/多样/对齐/偏好 |
| 25–45 | FID/IS/KID | 公式、假设、局限 |
| 45–60 | CLIPScore/P-R | 对齐/覆盖 |
| 60–75 | 评测设计 | prompt/seed/人工/任务 |
| 75–85 | 面试 | 90 秒 A4 |
| 85–90 | 小结 | 作业 |

### 3.2 板书布局

```text
左侧：四维度
中间：FID 公式 + 局限
右侧：CLIPScore/P-R
底部：评测方案（自动+人工+任务）
```

### 3.3 关键提问

- FID 为什么不衡量对齐？
- CLIPScore 为什么可被刷？
- Precision/Recall 怎么诊断？
- 不同论文 FID 能直接比吗？

### 3.4 常见卡点

| 卡点 | 处理 |
|---|---|
| FID 唯一论 | 讲 3 个反例 |
| CLIPScore 质量论 | 讲伪影 |
| 指标堆砌 | 用四维度归类 |
| 不看样本量 | 强调实现差异 |

## 4. 第 2 课：模式坍塌

### 4.1 时间安排（90 分钟）

| 时间 | 环节 | 内容 |
|---|---|---|
| 0–5 | 开场 | 什么叫坍塌 |
| 5–20 | 定义 | 坍塌 vs 丢弃 |
| 20–40 | 原因 | 对抗失衡/信号不足 |
| 40–60 | 方法 | 损失/多样性/训练/架构 |
| 60–75 | 诊断 | Precision/Recall/聚类 |
| 75–85 | 面试 | 90 秒 A9 |
| 85–90 | 小结 | 作业 |

### 4.2 板书布局

```text
左侧：坍塌 vs 丢弃
中间：原因（G/D 失衡）
右侧：方法分层（损失/多样性/训练）
底部：诊断（P/R、聚类、人眼）
```

### 4.3 关键提问

- 为什么 GAN 会坍塌？
- WGAN 为什么有效？
- truncation 能根治吗？
- Diffusion 会坍塌吗？

### 4.4 常见卡点

| 卡点 | 处理 |
|---|---|
| 只背 WGAN | 讲原因 |
| truncation 根治 | 讲权衡 |
| FID 正常=没坍塌 | 讲漏模式 |
| 说 Diffusion 没失败 | 列失败模式 |

## 5. 第 3 课：26 题 + 模拟面试

### 5.1 时间安排（90 分钟）

| 时间 | 环节 | 内容 |
|---|---|---|
| 0–5 | 开场 | 90 秒模板 |
| 5–25 | 分组串讲 | 6 组关键词 |
| 25–45 | 抽答 | 每人 2 题 + 追问 |
| 45–75 | 模拟面试 | 15 分钟一轮 |
| 75–85 | 反馈 | 评分 + 改进 |
| 85–90 | 总结 | 复习计划 |

### 5.2 板书布局

```text
左侧：90 秒四步
中间：26 题 6 组
右侧：追问树
底部：评分表
```

### 5.3 关键提问

- 一句话结论是什么？
- 公式/图在哪？
- 和相近方法比呢？
- 局限是什么？
- 不会时怎么答？

### 5.4 常见卡点

| 卡点 | 处理 |
|---|---|
| 没结构 | 四步模板 |
| 背全文 | 记钩子 |
| 不会硬编 | 诚实+推理 |
| 超时 | 计时练 |

---

## 6. 教学节奏控制

### 基础弱

- 先四维度，再指标；
- 坍塌只讲定义/原因/3 方法；
- 模拟面试 10 分钟。

### 基础好

- 加问 FID 的统计假设；
- 加问奖励模型偏差；
- 加问 Diffusion 失败模式；
- 45 分钟全真模拟。

### 时间不够

优先级：

1. FID/CLIPScore 局限；
2. 坍塌诊断；
3. 90 秒模板；
4. 模拟面试。

---

## 7. 课堂禁忌

- ❌ 不要现场跑 FID；
- ❌ 不要训练 GAN；
- ❌ 不要只背指标名；
- ❌ 不要模拟面试不留反馈；
- ❌ 不要让学生只背全文。
