# 第 6 章教学材料包：评估、失败模式与面试实战

> **定位**：面试学习，不是工程评测课。  
> **不要求**跑 FID、不要求训练 GAN、不要求搭评测平台。  
> **要求**：能解释指标、能诊断失败、能结构化回答 26 题、能完成模拟面试。

---

## 1. 这一包材料解决什么问题

第 6 章对应：

- A4：图像生成评估指标；
- A9：GAN 模式坍塌；
- 26 题串讲与模拟面试（全课程收口）。

三条线：

```text
怎么评：FID/CLIPScore/Precision-Recall/人工
        ↓
怎么诊断：模式坍塌/漏模式/过饱和/对齐失败
        ↓
怎么表达：90 秒回答 + 追问 + 模拟面试
```

学完这一包，你能把“我觉得这个模型好”变成“用哪些指标、为什么、局限是什么”。

## 3. 建议学习顺序

### 自学版（约 5–6 小时）

1. 读 6.1，做“场景—指标”表；
2. 读 6.2，做“坍塌诊断表”；
3. 读 6.3，按 26 题清单自测；
4. 做 06 练习；
5. 用 05 做 90 秒回答；
6. 录一次 15 分钟模拟面试。

### 授课版（3 节 × 90 分钟）

- 第 1 节：6.1；
- 第 2 节：6.2；
- 第 3 节：6.3 + 模拟面试。

## 4. 本章不做什么

- 不跑 FID/CLIPScore；
- 不训练 GAN；
- 不搭评测平台；
- 不做大规模人工评估。

本章只保留指标含义、诊断逻辑和面试表达。

## 7. 设计原则

> **指标不是越多越好，而是“指标—任务—局限”匹配。**

面试时先问“评什么”，再选指标；不要一上来背 FID。
