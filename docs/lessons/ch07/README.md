# 第 7 章教学材料包：综合练习与面试答辩

> **定位**：面试综合练习，不是工程实现项目。  
> **不要求**写完整代码、不要求训练模型、不要求搭 demo。  
> **要求**：把第 1–6 章知识整合成可展示的推导、方案和答辩。

---

## 1. 这一包材料解决什么问题

第 7 章不再引入新知识，而是做三件事：

1. 把 DDPM/DDIM/采样公式串成一页纸；
2. 把 CLIP/ControlNet/IP-Adapter/LoRA 组合成一个方案；
3. 把评测/项目/取舍讲成 10 分钟答辩。

三条线：

```text
纸面推导（D5/D9/D1/D4/D3）
        ↓
方案设计（A12/A13/A14/A10）
        ↓
评测 + 答辩（A4/A6/A7/A11）
```

## 3. 建议顺序

### 自学版（约 4–5 小时）

1. 做 7.1 一页纸；
2. 做 7.2 架构图；
3. 做 7.3 评测表；
4. 用 05 自问自答；
5. 录 10 分钟答辩。

### 工作坊版（3 次 × 90 分钟）

- 第 1 次：7.1；
- 第 2 次：7.2；
- 第 3 次：7.3 + 答辩。

---

## 4. 本章不做什么

- 不写完整 DDPM 代码；
- 不训练 LoRA/ControlNet；
- 不搭 demo；
- 不跑 FID。

本章产出是**纸面/口述/架构图**，不是 repo。
