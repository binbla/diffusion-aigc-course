# 答案与解析

## 一、概念题答案

### 1. SDXL 四项改动

- 双文本编码器；
- 更大 UNet；
- micro-conditioning；
- base + refiner。

### 2. 双文本编码器为什么有效

CLIP-L 和 OpenCLIP bigG 的训练数据/语义不同，拼接提供更丰富表示；pooled embedding 提供全局条件。

### 3. micro-conditioning 解决什么

训练随机裁剪导致构图偏移；告诉模型原图尺寸/裁剪坐标/目标尺寸，让它学会补偿。

### 4. base + refiner

- base：主体结构/语义/构图；
- refiner：低强度 img2img 精修细节；
- refiner 可选。

### 5. MMDiT vs Cross-Attention

Cross-attn 是图像查文本、单向；MMDiT 把文本/图像 token 拼接做联合 attention，双向，不同模态独立投影。

### 6. Rectified Flow vs DDPM

DDPM 是随机前向 + 去噪；Flow 是确定性直线路径 + 速度回归，采样解 ODE。

### 7. SD3 为什么加 T5

CLIP 77 token/组合性限制；T5 适合长文本、计数、文字渲染。

### 8. DALL·E 2 prior

把文本嵌入映射到 CLIP 图像嵌入，桥接模态 gap，供 decoder 条件使用。

## 二、推导题答案

### 9. Flow 插值和速度

$$
x_t=(1-t)x_0+t\epsilon,
\qquad
v=\epsilon-x_0.
$$

### 10. Flow 损失

$$
\mathcal L
=\mathbb E\left[
\|v_\theta(x_t,t)-(\epsilon-x_0)\|^2
\right].
$$

### 11. Euler 采样

$$
x_{t-\Delta}=x_t-\Delta\,v_\theta(x_t,t).
$$

### 12. base + refiner

1. base 从噪声生成 latent；
2. refiner 以 base latent 为输入，做低强度 img2img；
3. VAE 解码。

### 13. 条件注入对比

- SD：文本 token → cross-attention 的 K/V；
- DALL·E 2：文本 → prior → CLIP image embedding → decoder 条件。
