# 第 1 章教学材料包：扩散模型基础

> **定位**：面试学习，不是工程实现课。  
> **不要求**写完整 DDPM、不要求训练模型、不要求复现论文。  
> **要求**：能推导、能解释、能比较、能用 90 秒回答，并接住两层追问。

---

## 1. 这一包材料解决什么问题

第 1 章对应 6 道高频题：

- D2：能不能用非高斯噪声？
- D5：推演 DDPM 公式；
- D6：GAN 和 Diffusion 的区别；
- D9：实现 DDPM 需要什么条件；
- D10：为什么加噪幅度不一致？
- A3：重参数技巧。

这 6 道题看起来分散，实际上是一条链：

```text
生成模型全景（为什么需要 Diffusion）
        ↓
前向过程（怎么加噪、为什么能一步采样）
        ↓
反向过程（怎么去噪、DDPM 在优化什么）
        ↓
变体与边界（高斯是不是必须、Flow 是什么）
        ↓
面试表达（90 秒 + 追问）
```

学完这一包，你不是“背过 DDPM”，而是能站在白板前，从 $q(x_t\mid x_{t-1})$ 一路写到采样公式，并解释每一步为什么成立。

## 3. 建议学习顺序

### 自学版（约 6–8 小时）

1. 读 01，画一张生成模型对比表；
2. 读 02，自己推一遍 $q(x_t\mid x_0)$，做数值例子；
3. 读 03，白板推后验和 ELBO；
4. 读 04，回答“高斯是不是必须”；
5. 做 06 的练习，对答案；
6. 用 05 做 90 秒回答；
7. 用 08 检查自己是否理解材料边界。

### 授课版（4 节 × 90 分钟）

- 第 1 节：01 + 02 前半；
- 第 2 节：02 后半 + 03 前半；
- 第 3 节：03 后半；
- 第 4 节：04 + 05 + 模拟面试。

详细节奏见 [07-讲师手册](07-讲师手册.md)。

### 面试前复习版（60 分钟）

1. 看 [公式速查](../../formulas.md) 的 1–4 节；
2. 看 05 的“核心 6 题”；
3. 用 06 的“白板题”手写一遍；
4. 录一段 10 分钟自述。

## 4. 本章不做什么

为了避免把学习课变成工程课，本章**刻意不做**：

- 不写完整 DDPM 训练/采样代码；
- 不训练 toy 模型；
- 不实现 U-Net；
- 不跑 FID；
- 不要求复现论文结果。

代码只在“帮助理解”的层面出现：例如 5 行伪代码说明训练循环，不要求运行。真正的工程实现放在可选扩展，不影响面试主线。

> 原因：面试考的是“你能不能解释和推导”，不是“你能不能复现”。完整代码会占用大量时间，却不一定提升面试表达。
