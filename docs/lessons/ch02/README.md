# 第 2 章教学材料包：采样、加速与引导

> **定位**：面试学习，不是工程实现课。  
> **不要求**实现采样器、不要求跑 benchmark、不要求训练蒸馏模型。  
> **要求**：能解释采样公式、能比较方法、能选型、能用 90 秒回答 D1/D3/D4/D8。

---

## 1. 这一包材料解决什么问题

第 2 章对应 4 道高频题：

- D1：扩散模型有哪些常见采样方式？
- D3：你了解哪些 Diffusion 加速方法？
- D4：DDPM 和 DDIM 的关系？
- D8：classifier-free guidance 和 classifier guidance 的区别？

这四道题其实是一条链：

```text
怎么从噪声走回数据（D1）
        ↓
DDPM 随机采样 vs DDIM 确定性采样（D4）
        ↓
如何少走几步（D3：solver / 蒸馏 / 缓存）
        ↓
如何走得更“像 prompt”（D8：guidance）
```

学完这一包，你能在面试中把“采样器、加速、引导”分开讲，而不是把它们混成一句“用 DDIM 加速”。

## 3. 建议学习顺序

### 自学版（约 6–8 小时）

1. 读 2.1，写出 DDPM/DDIM 采样公式；
2. 读 2.2，画一张采样器分类表；
3. 读 2.3，做一张加速方案选型表；
4. 读 2.4，推 CFG 并解释 $w$；
5. 做 06 练习，对答案；
6. 用 05 做 90 秒回答；
7. 用 08 检查边界。

### 授课版（4 节 × 90 分钟）

- 第 1 节：2.1；
- 第 2 节：2.2 + 2.3（重点：分类与选型）；
- 第 3 节：2.4；
- 第 4 节：05 + 06 + 模拟面试。

详细节奏见 [07 讲师手册](07-讲师手册.md)。

### 面试前复习版（45 分钟）

1. 看 [公式速查](../../formulas.md) 的 DDIM/CFG 两节；
2. 看 05 的 4 道核心题；
3. 手写 DDIM 更新式和 CFG 公式；
4. 用 3 分钟讲“采样器怎么选”。

## 4. 本章不做什么

- 不实现 DDIM/DPM-Solver；
- 不跑采样器 benchmark；
- 不训练 LCM/Turbo/DMD；
- 不做显存/时延优化。

本章只保留公式、对比表、选择逻辑和面试表达。  
需要代码时，应作为“可选实验”，不进入主线。

## 7. 设计原则

> **采样器是“怎么走”，加速是“少走几步/每步更快”，引导是“往哪个方向走”。**

三件事必须分开讲，否则面试很容易把 DDIM、LCM、CFG 混成一锅。
