# 扩展篇：2023–2026 扩散模型高影响论文地图

> **范围**：2023–2026 年扩散/Flow/视频/3D/对齐/评估方向的高影响工作。  
> **写法**：名字、影响力、星级、一句话描述、做了什么、大贡献、论文链接、面试怎么用。  
> **说明**：引用数在不同数据库（Google Scholar / OpenAlex / Semantic Scholar）差异很大，且 2026 年论文引用尚未积累，因此本表用 **S/A/B 影响力 + 星级**，不写死具体引用数字。  
> **S** ≈ 领域基石/必读；**A** ≈ 高影响/方向代表；**B** ≈ 新近/专题。  
> **星级**是“面试 + 学习价值”的综合推荐，不等于纯引用量。

## 1. 架构与训练范式

### 1.1 DiT：Scalable Diffusion Models with Transformers（2023）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：用 Transformer 替换 UNet，把 latent patch 当 token 做扩散。
- **做了什么**：patchify latent、adaLN-Zero 注入时间/类别条件、按 Gflops 做 scaling。
- **大贡献**：证明扩散模型可以像 Transformer 一样 scale；成为 SD3/MMDiT/Sora 类架构的前身。
- **面试怎么用**：回答“为什么从 UNet 转向 Transformer”“DiT 和 UNet 的区别”。
- **链接**：[arXiv:2212.09748](https://arxiv.org/abs/2212.09748)

### 1.2 SDXL（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：1024 时代的多条件 LDM：双文本编码器 + micro-conditioning + refiner。
- **做了什么**：CLIP-L + OpenCLIP bigG、原图尺寸/裁剪/目标尺寸条件、base + refiner。
- **大贡献**：把 SD 从 512 推到 1024，并系统化多宽高比/裁剪条件。
- **面试怎么用**：A10 的标准答案骨架。
- **链接**：[arXiv:2307.01952](https://arxiv.org/abs/2307.01952)

### 1.3 PixArt-α（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：低成本训练 DiT 文生图，证明 Transformer T2I 不一定贵。
- **做了什么**：三阶段训练分解、cross-attention DiT、密集伪 caption。
- **大贡献**：把 DiT 训练成本打下来；影响后续 PixArt-Σ/Sana 等。
- **面试怎么用**：回答“DiT 怎么注入文本”“怎么降低训练成本”。
- **链接**：[arXiv:2310.00426](https://arxiv.org/abs/2310.00426)

### 1.4 SD3：Scaling Rectified Flow Transformers（2024）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：MMDiT + Rectified Flow + T5 + 16ch VAE，SD 的范式切换。
- **做了什么**：文本/图像 token 联合注意力、直线 Flow、三文本编码器、16 通道 VAE。
- **大贡献**：证明 Rectified Flow + 多模态 Transformer 可以超过 UNet 扩散；文字/复杂 prompt 明显提升。
- **面试怎么用**：A11 的核心；回答“MMDiT 与 cross-attn 区别”“Flow 与 DDPM 关系”。
- **链接**：[arXiv:2403.03206](https://arxiv.org/abs/2403.03206)

### 1.5 Sana（2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：线性注意力 DiT + 32 倍压缩 VAE，把 4K 生成做到笔记本可跑。
- **做了什么**：深度压缩 AE、Linear DiT、decoder-only 文本编码器、Flow-DPM-Solver。
- **大贡献**：把“高分辨率 + 高效率”推到端侧；证明架构/压缩/采样可以协同优化。
- **面试怎么用**：回答“高分辨率 Diffusion 怎么降成本”“线性注意力是否够用”。
- **链接**：[arXiv:2410.10629](https://arxiv.org/abs/2410.10629)

### 1.6 SiT（2024）

- **影响力**：B｜**推荐**：★★★☆☆
- **一句话**：用 interpolant 框架系统比较 Flow/Diffusion 的设计选择。
- **做了什么**：在 DiT 骨架上研究离散/连续时间、目标、插值、随机/确定采样。
- **大贡献**：把 Flow Matching 和 Diffusion 的统一视角讲清楚；同结构下超过 DiT。
- **面试怎么用**：回答“Flow 和 Diffusion 到底差在哪”。
- **链接**：[arXiv:2401.08740](https://arxiv.org/abs/2401.08740)

## 2. 加速与少步生成

### 2.1 Consistency Models（2023）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：学习“任意时刻都映射到同一个 $x_0$”的一致性函数，支持 1 步/少步。
- **做了什么**：一致性映射、边界条件、一致性蒸馏/独立训练。
- **大贡献**：少步生成的理论代表；LCM/一致性蒸馏的直接前身。
- **面试怎么用**：回答“LCM 为什么能 1–4 步”“一致性模型和蒸馏区别”。
- **链接**：[arXiv:2303.01469](https://arxiv.org/abs/2303.01469)

### 2.2 LCM：Latent Consistency Models（2023）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：把一致性蒸馏搬到 latent，SD 可以 2–4 步出图。
- **做了什么**：把 CFG 的反向过程当 augmented PF-ODE，直接预测 ODE 解；LCF 微调。
- **大贡献**：让少步 SD 真正可用；32 A100 小时训练 768 LCM。
- **面试怎么用**：回答“LCM 和 Turbo 区别”“少步模型怎么训”。
- **链接**：[arXiv:2310.04378](https://arxiv.org/abs/2310.04378)

### 2.3 LCM-LoRA（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：把 LCM 蒸馏成 LoRA，即插即用地加速各种 SD 模型。
- **做了什么**：LoRA 蒸馏、跨模型/跨 LoRA 通用加速模块。
- **大贡献**：少步能力“模块化”；不用为每个模型单独蒸馏。
- **面试怎么用**：回答“LCM-LoRA 为什么能通用”“和普通 LoRA 区别”。
- **链接**：[arXiv:2311.05556](https://arxiv.org/abs/2311.05556)

### 2.4 ADD / SDXL-Turbo（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：对抗蒸馏 + score distillation，把 SDXL 压到 1–4 步。
- **做了什么**：教师 score 蒸馏 + 判别器对抗损失；单步/少步生成。
- **大贡献**：少步模型的质量上限被明显推高；推动实时文生图。
- **面试怎么用**：回答“Turbo 为什么快”“为什么 Turbo 要低 CFG”。
- **链接**：[arXiv:2311.17042](https://arxiv.org/abs/2311.17042)

### 2.5 DMD / DMD2（2023/2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：分布匹配蒸馏，把多步扩散压成一步/少步，同时保多样性。
- **做了什么**：DMD 用两个 score 的差做 KL；DMD2 去掉回归损失、加 GAN、支持多步。
- **大贡献**：少步生成从“像教师”走向“匹配教师分布”；DMD2 在 ImageNet/COCO 上很强。
- **面试怎么用**：回答“DMD 和 LCM 区别”“少步模型怎么保多样性”。
- **链接**：[DMD arXiv:2311.18828](https://arxiv.org/abs/2311.18828)、[DMD2 arXiv:2405.14867](https://arxiv.org/abs/2405.14867)

### 2.6 SnapFusion（2023）

- **影响力**：B｜**推荐**：★★★☆☆
- **一句话**：把文生图扩散做到手机端 2 秒内。
- **做了什么**：高效 UNet、step distillation、CFG 正则。
- **大贡献**：端侧部署的代表；证明 8 步可以接近 50 步 SD1.5。
- **面试怎么用**：回答“端侧 Diffusion 怎么优化”。
- **链接**：[arXiv:2306.00980](https://arxiv.org/abs/2306.00980)

## 3. 条件控制、编辑与个性化

### 3.1 ControlNet（2023）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：冻结 SD + 可训练副本 + 零卷积，把边缘/深度/姿态注入。
- **做了什么**：locked copy、trainable copy、condition encoder、zero convolution。
- **大贡献**：空间控制的事实标准；开启 SD 可控生成生态。
- **面试怎么用**：A13 的核心；解释 zero conv 和“只训分支”。
- **链接**：[arXiv:2302.05543](https://arxiv.org/abs/2302.05543)

### 3.2 IP-Adapter（2023）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：用 CLIP 图像特征做 image prompt，解耦文本/图像 cross-attention。
- **做了什么**：图像编码器 + 投影 + 两套 K/V；只训 22M 参数。
- **大贡献**：图像 prompt 的轻量标准方案；与 ControlNet 互补。
- **面试怎么用**：A14 的核心；解释“为什么解耦”。
- **链接**：[arXiv:2308.06721](https://arxiv.org/abs/2308.06721)

### 3.3 InstructPix2Pix（2022/2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：用“指令 + 输入图”直接做前向编辑，不需要逐图 inversion。
- **做了什么**：GPT-3 + SD 合成编辑数据；条件扩散模型训练。
- **大贡献**：指令编辑的代表；把编辑变成一次前向。
- **面试怎么用**：回答“指令编辑和 DDIM inversion 区别”。
- **链接**：[arXiv:2211.09800](https://arxiv.org/abs/2211.09800)

### 3.4 InstantID（2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：单张人脸图 + IdentityNet，零样本 ID 保持。
- **做了什么**：人脸/关键点条件、IdentityNet、与文本 prompt 结合。
- **大贡献**：ID 个性化从“训练”走向“推理时插件”；和 IP-Adapter 互补。
- **面试怎么用**：回答“PhotoMaker/InstantID/LoRA 区别”。
- **链接**：[arXiv:2401.07519](https://arxiv.org/abs/2401.07519)

### 3.5 PhotoMaker（2023）

- **影响力**：A｜**推荐**：★★★☆☆
- **一句话**：stacked ID embedding，把多张 ID 图压成一个统一表示。
- **做了什么**：ID 堆叠嵌入、ID 导向数据管线。
- **大贡献**：少样本 ID 定制，兼顾效率与可控性。
- **面试怎么用**：回答“ID 定制有哪些路线”。
- **链接**：[arXiv:2312.04461](https://arxiv.org/abs/2312.04461)

### 3.6 PuLID（2024）

- **影响力**：B｜**推荐**：★★★☆☆
- **一句话**：对比对齐 + ID loss，做到“纯”且“快”的 ID 定制。
- **做了什么**：Lightning T2I 分支、contrastive alignment、ID loss。
- **大贡献**：减少 ID 插入对原图风格/构图的破坏。
- **面试怎么用**：回答“ID 定制怎么兼顾保真与可编辑性”。
- **链接**：[arXiv:2404.16022](https://arxiv.org/abs/2404.16022)

## 4. 视频、3D 与世界模型

### 4.1 Stable Video Diffusion（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：把 latent video diffusion 系统化：图像预训练 → 视频预训练 → 高质量微调。
- **做了什么**：视频数据 curation、时序层、text-to-video/image-to-video。
- **大贡献**：开源视频扩散的强基线；证明数据 curation 是关键。
- **面试怎么用**：回答“视频扩散怎么从图像模型迁移”。
- **链接**：[arXiv:2311.15127](https://arxiv.org/abs/2311.15127)

### 4.2 Sora（2024）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：把视频生成讲成“world simulator”，用大规模视频 + Transformer 做长时长高保真生成。
- **做了什么**：视频压缩到时空 latent、扩散 Transformer、长视频生成。
- **大贡献**：把视频生成从“短片段”推向“世界模型”叙事；影响 2024–2026 视频路线。
- **面试怎么用**：回答“Sora 和 SVD 区别”“视频扩散的难点”。
- **链接**：[OpenAI technical report](https://openai.com/index/video-generation-models-as-world-simulators/)（非 arXiv）

### 4.3 CogVideoX（2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：3D VAE + expert Transformer，做 10 秒、768×1360 的文生视频。
- **做了什么**：3D 因果 VAE、expert adaptive LayerNorm、渐进训练、视频 caption。
- **大贡献**：开源视频 DiT 的代表；把长时长/运动/文本对齐一起推进。
- **面试怎么用**：回答“视频 VAE 和图像 VAE 区别”“视频 DiT 怎么注入文本”。
- **链接**：[arXiv:2408.06072](https://arxiv.org/abs/2408.06072)

### 4.4 HunyuanVideo（2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：13B 开源视频生成框架，强调数据/架构/训练/推理的系统工程。
- **做了什么**：数据 curation、视频 DiT、渐进 scaling、高效推理。
- **大贡献**：开源视频模型规模上探；与闭源模型可比。
- **面试怎么用**：回答“开源视频模型到什么水平”“视频训练最难的是什么”。
- **链接**：[arXiv:2412.03603](https://arxiv.org/abs/2412.03603)

### 4.5 Wan（2025）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：开放视频基础模型套件，1.3B/14B，覆盖 T2V/I2V/编辑/个性化。
- **做了什么**：新 VAE、scalable 预训练、数据 curation、自动评测；消费级 1.3B。
- **大贡献**：把开源视频模型推到“多任务 + 消费级可跑”。
- **面试怎么用**：回答“2025 视频生成格局”“开源 vs 闭源”。
- **链接**：[arXiv:2503.20314](https://arxiv.org/abs/2503.20314)

### 4.6 DreamFusion（2022）

- **影响力**：S｜**推荐**：★★★★★
- **一句话**：用 2D 扩散先验 + SDS，从文本优化 3D NeRF。
- **做了什么**：Score Distillation Sampling，把 2D 扩散 score 蒸馏到 3D 渲染。
- **大贡献**：开启 text-to-3D 的“2D lifting”路线。
- **面试怎么用**：回答“SDS 是什么”“2D 扩散怎么用于 3D”。
- **链接**：[arXiv:2209.14988](https://arxiv.org/abs/2209.14988)

### 4.7 MVDream（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：多视角扩散，生成一致的多视角图像，作为 3D 先验。
- **做了什么**：多视角注意力、2D+3D 数据训练、SDS 结合。
- **大贡献**：解决 2D lifting 的多视角不一致（Janus 问题）。
- **面试怎么用**：回答“多视角一致性怎么保证”。
- **链接**：[arXiv:2308.16512](https://arxiv.org/abs/2308.16512)

### 4.8 InstantMesh（2024）

- **影响力**：B｜**推荐**：★★★☆☆
- **一句话**：多视角扩散 + 稀疏视图重建，10 秒内单图生成 3D mesh。
- **做了什么**：多视角扩散、LRM 重建、可微等值面提取。
- **大贡献**：feed-forward 3D 生成的工程代表。
- **面试怎么用**：回答“3D 生成从优化走向 feed-forward”。
- **链接**：[arXiv:2404.07191](https://arxiv.org/abs/2404.07191)

## 5. 对齐、偏好与评估

### 5.1 DDPO（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：把去噪当多步 MDP，用策略梯度优化下游奖励。
- **做了什么**：denoising diffusion policy optimization；奖励可以是压缩性/审美/VLM。
- **大贡献**：扩散 RLHF 的代表；开启“用奖励优化扩散”。
- **面试怎么用**：回答“Diffusion 怎么做 RLHF”。
- **链接**：[arXiv:2305.13301](https://arxiv.org/abs/2305.13301)

### 5.2 Diffusion-DPO（2023/2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：把 DPO 搬到扩散，用偏好对直接优化模型。
- **做了什么**：用 ELBO 构造可微偏好目标；在 Pick-a-Pic 上微调 SDXL。
- **大贡献**：扩散对齐的简单强基线；比 RLHF 更稳。
- **面试怎么用**：回答“Diffusion-DPO 和 DDPO 区别”。
- **链接**：[arXiv:2311.12908](https://arxiv.org/abs/2311.12908)

### 5.3 ImageReward（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：第一个通用文生图人类偏好奖励模型。
- **做了什么**：13.7 万专家比较、奖励模型、ReFL 微调。
- **大贡献**：把“人类偏好”变成可优化目标；评估/对齐都用得上。
- **面试怎么用**：回答“奖励模型怎么做”“ReFL 是什么”。
- **链接**：[arXiv:2304.05977](https://arxiv.org/abs/2304.05977)

### 5.4 HPSv2（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：大规模人类偏好数据集 + CLIP 微调评分模型。
- **做了什么**：HPD v2（79.8 万选择）、HPS v2、文生图 benchmark。
- **大贡献**：比 FID/CLIPScore 更接近人类偏好；常用评估基线。
- **面试怎么用**：回答“HPSv2 和 CLIPScore 区别”。
- **链接**：[arXiv:2306.09341](https://arxiv.org/abs/2306.09341)

### 5.5 GenEval（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：面向对象组合能力的评测：共现、位置、计数、颜色。
- **做了什么**：对象检测 + 颜色分类 + 组合 prompt 集。
- **大贡献**：补上 FID/CLIPScore 缺失的“组合能力”评估。
- **面试怎么用**：回答“怎么评估计数/空间/属性绑定”。
- **链接**：[arXiv:2310.11513](https://arxiv.org/abs/2310.11513)

### 5.6 VQAScore（2024）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：用 VQA 模型判断“这张图是否展示了这段文本”，评估复杂对齐。
- **做了什么**：VQA 概率作为对齐分数；GenAI-Bench 组合 prompt。
- **大贡献**：比 CLIPScore 更擅长复杂组合/关系；可扩展到视频/3D。
- **面试怎么用**：回答“CLIPScore 不够怎么办”。
- **链接**：[arXiv:2404.01291](https://arxiv.org/abs/2404.01291)

## 6. 离散扩散、语言与科学应用

### 6.1 LLaDA（2025）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：从零训练的扩散语言模型，挑战“LLM 必须自回归”的假设。
- **做了什么**：mask 前向 + 反向生成、Transformer 预测 masked token、SFT。
- **大贡献**：8B 扩散 LLM 可对标 LLaMA3 8B；展示扩散在语言上的可扩展性。
- **面试怎么用**：回答“扩散能生成文本吗”“和 AR 的区别”。
- **链接**：[arXiv:2502.09992](https://arxiv.org/abs/2502.09992)

### 6.2 MaskGIT（2022）

- **影响力**：A｜**推荐**：★★★☆☆
- **一句话**：用 mask 预测做离散 token 的并行生成/补全。
- **做了什么**：masked visual token modeling、迭代解码。
- **大贡献**：离散生成的重要 baseline；影响后续 masked diffusion。
- **面试怎么用**：回答“离散扩散/掩码生成和连续扩散区别”。
- **链接**：[arXiv:2202.04200](https://arxiv.org/abs/2202.04200)

### 6.3 DiffDock（2023）

- **影响力**：A｜**推荐**：★★★☆☆
- **一句话**：把分子对接建模成非欧几里得空间上的扩散。
- **做了什么**：平移/旋转/扭转的扩散过程、置信度估计。
- **大贡献**：扩散在药物设计/科学计算中的代表应用。
- **面试怎么用**：回答“扩散除了图像还能做什么”。
- **链接**：[arXiv:2210.01776](https://arxiv.org/abs/2210.01776)

### 6.4 AudioLDM（2023）

- **影响力**：B｜**推荐**：★★★☆☆
- **一句话**：在 CLAP latent 上做文本到音频的 latent diffusion。
- **做了什么**：CLAP 音频 embedding、latent diffusion、文本引导。
- **大贡献**：音频生成的代表；证明 LDM 可跨模态。
- **面试怎么用**：回答“音频扩散和图像扩散的差异”。
- **链接**：[arXiv:2301.12503](https://arxiv.org/abs/2301.12503)

### 6.5 Diffusion Policy（2023）

- **影响力**：A｜**推荐**：★★★★☆
- **一句话**：把机器人 visuomotor policy 建模成条件去噪过程。
- **做了什么**：动作序列扩散、receding horizon、视觉条件、time-series transformer。
- **大贡献**：扩散在机器人策略学习中的代表；多模态动作分布友好。
- **面试怎么用**：回答“扩散在决策/机器人怎么用”。
- **链接**：[arXiv:2303.04137](https://arxiv.org/abs/2303.04137)

## 8. 2026 观察：先别按引用排序

截至 2026-10，2026 年论文的引用量还在积累，不适合排“高引榜”。但可以看四条线：

1. **实时视频/世界模型**：Sora、Wan、HunyuanVideo 之后，重点是长时长、物理一致性、实时交互；
2. **离散扩散 LLM**：LLaDA 之后，masked diffusion 与 AR 的混合、推理效率；
3. **3D/4D 资产**：多视角扩散 + feed-forward 重建 + 3DGS/4D；
4. **偏好/安全/可编辑**：DPO、奖励模型、概念擦除、水印、版权。

面试时如果被问“2026 有什么新进展”，不要硬背论文名；说清这四条线 + 一个代表工作即可。

## 9. 面试延伸 15 问

1. **DiT 和 UNet 的区别？**  
   latent patch token + Transformer + adaLN；更容易 scale，但高分辨率 token 成本高。

2. **Flow Matching 和 DDPM 的区别？**  
   Flow 学速度场/概率路径，采样解 ODE；DDPM 学噪声/去噪，采样随机 SDE。

3. **Rectified Flow 为什么能少步？**  
   轨迹更直，ODE 积分更容易；不是严格 1 步。

4. **Consistency Model 和蒸馏的区别？**  
   一致性学习“任意时刻到 $x_0$”的映射；蒸馏可以是渐进/对抗/分布匹配。

5. **LCM 和 Turbo 的区别？**  
   LCM 一致性蒸馏；Turbo 对抗蒸馏 + 教师约束；都少步，但训练信号不同。

6. **视频扩散比图像难在哪？**  
   时空建模、数据/计算、长时长一致性、运动/物理、评测。

7. **Sora 的“world simulator”是什么意思？**  
   把视频生成当作学习世界动态；不是严格物理引擎，但强调规模/一致性。

8. **SDS 是什么？**  
   用 2D 扩散 score 蒸馏到 3D 渲染，让 2D 先验指导 3D 优化。

9. **指令编辑和反演编辑的区别？**  
   InstructPix2Pix 一次前向；DDIM inversion/Prompt-to-Prompt 需要反演/注意力控制。

10. **ID 定制有哪些路线？**  
    LoRA/DreamBooth（训练）、IP-Adapter（图像 prompt）、PhotoMaker/InstantID/PuLID（ID 适配）。

11. **DDPO 和 Diffusion-DPO 的区别？**  
    DDPO 是策略梯度 RL；DPO 直接用偏好对做分类式优化。

12. **FID 之外怎么评？**  
    CLIPScore/GenEval/VQAScore/HPSv2/人工；组合能力要专门 benchmark。

13. **扩散 LLM 和 AR 的区别？**  
    并行/迭代去噪 vs 逐 token 自回归；扩散可双向、但推理步数和质量仍是挑战。

14. **2026 的趋势？**  
    实时视频/世界模型、离散扩散 LLM、3D/4D、偏好/安全。

15. **怎么读一篇新论文？**  
    先看问题/贡献/限制，再看方法图/公式，最后用 90 秒讲出来。
