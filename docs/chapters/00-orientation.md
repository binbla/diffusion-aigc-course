# 第 0 章 导学：从面试题到能力地图

> **课时**：1 节 / 90 分钟  
> **前置**：无  
> **章节定位**：把 26 道面试题拆成一张可执行的能力地图，建立全课程的学习节奏。

---

## 章节目标

完成本章后，你应该能够：

1. 说清楚这门课解决什么问题：不是背答案，而是建立“公式—架构—训练—评测—表达”五层能力；
2. 把 26 道题归类到 8 个章节，知道每道题在哪个课时被讲透；
3. 完成一次基线自测，找出自己的三个最大短板；
4. 选定学习路径：2 周速通、6 周标准或 8 周深入；
5. 搭好 PyTorch / diffusers / Jupyter 学习环境。

---

## 0.1 课程导学与自测

### 本节要回答的问题

- 这 26 道题背后，面试官到底在考什么？
- 为什么“会背 DDPM 公式”不等于“能通过面试”？
- 我应该按什么顺序学，先补数学还是先做推导？
- 每节课要产出什么，怎么知道自己学会了？

### 讲什么

1. **面试能力模型**
   - 公式推导：DDPM、DDIM、CFG、CLIP loss、ELBO；
   - 架构理解：U-Net、DiT、MMDiT、VAE、Cross-Attention；
   - 训练工程：数据、schedule、CFG dropout、EMA、显存；
   - 评测分析：FID、CLIPScore、Precision/Recall、人工评估；
   - 表达结构：90 秒回答、对比表、白板推导、项目讲述。
2. **26 题地图**
   - Diffusion 10 题：采样、噪声、加速、DDPM/DDIM、GAN 对比、Offset Noise、Guidance、实现条件、噪声幅度；
   - AIGC 16 题：CLIP、AE/VAE/VQ-VAE、重参数、评估、SD/SDXL/SD3、DALL·E 2、Cross-Attention、GAN 坍塌、LoRA 系列、ControlNet、IP-Adapter。
3. **课程结构**
   - 第 0 章：导学；
   - 第 1 章：扩散基础；
   - 第 2 章：采样、加速、引导；
   - 第 3 章：Latent Diffusion 与 SD；
   - 第 4 章：条件控制与个性化；
   - 第 5 章：模型演进与系统对比；
   - 第 6 章：评估、失败模式、面试实战；
   - 第 7 章：综合练习与面试答辩。
4. **学习路径**
   - 2 周速通：只学 12 节核心课，目标是把高频题讲顺；
   - 6 周标准：26 节 + 2 个综合练习，目标是能面试 + 有可讲的推导/方案；
   - 8 周深入：26 节 + 3 个综合练习 + 模拟面试，目标是冲击更高岗位。
5. **工具与环境**
   - Python 3.10+、PyTorch 2.x；
   - `diffusers`、`transformers`、`accelerate`、`datasets`；
   - Jupyter/Colab；
   - 可选：ComfyUI 或 A1111 做可视化实验；
   - 显存建议：toy 实验 CPU 可跑；SD 实验建议 8GB+ VRAM，低显存用 SD1.5 + 512。

### 学什么

完成本节后，你应该能：

- 用一张表说出 8 个章节各自解决什么问题；
- 把任意一道题定位到具体课时；
- 用 3 分钟做一次自我诊断：数学、推导、方案、表达四项各打 1–5 分；
- 选出一条适合自己的学习路径，并写下每周时间预算；
- 跑通环境检查脚本（`torch`、`diffusers`、`transformers` 版本）。

### 对应面试题

- 全课程导览，不直接对应单题；
- 可作为开场自我介绍和项目经历的整理框架。

### 课堂练习

1. **基线自测（20 分钟）**
   - 从题库中随机抽 5 题，每題写 3 个关键词；
   - 标记“能讲清 / 只会背 / 完全不会”；
   - 统计三类占比。
2. **能力雷达（10 分钟）**
   - 数学推导、白板表达、架构理解、评测分析、表达沟通，各 1–5 分；
   - 选最低的两项，作为前两周重点。
3. **路径选择（10 分钟）**
   - 在 2 周 / 6 周 / 8 周中选一个；
   - 把每周可用时间写进日历。

### 课后作业

- 完成一份 `self-assessment.md`：26 题逐题标记掌握度；
- 写 300 字：我为什么学 Diffusion/AIGC，目标岗位是什么；
- 跑通环境，保存版本截图。

### 验收标准

- 能不看目录说出 8 个章节的名称和顺序；
- 能解释“为什么本课程先讲前向过程，再讲反向和采样”；
- 自测表完成度 100%，并选出三个优先补强点。

### 常见误区

- 一上来就背 DDPM 公式，不知道公式在整条链路中的位置；
- 只学文生图应用，不补 VAE、Attention、训练细节；
- 把“看过”当成“会讲”，没有输出和复述。
