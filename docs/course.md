# 课程总览：Diffusion / AIGC 面试课堂

> **一句话**：把 26 道高频面试题，拆成 8 章、26 节课、3 个综合练习，形成一条“能推导、能解释、能评测、能表达”的学习路径。

---

## 1. 这门课解决什么问题

很多人的复习方式是“背题”：能说出 DDPM 有前向和反向，但被追问“为什么后验是高斯”“为什么预测噪声”“DDIM 为什么能跳步”就卡住。

这门课不按题背，而按**能力链**组织：

```text
生成模型直觉
   ↓
DDPM 数学推导
   ↓
采样 / 加速 / 引导
   ↓
Latent Diffusion 与 SD 架构
   ↓
条件控制与个性化
   ↓
模型演进与系统对比
   ↓
评测、失败模式、面试表达
   ↓
面试表达与综合练习
```

学完后，你应能：

- 在白板上推导 DDPM 的前向、后验、ELBO 和采样；
- 解释 DDIM、DPM-Solver、LCM、Rectified Flow 的关系；
- 画清 SD / SDXL / SD3 的架构演进；
- 讲清 CLIP、ControlNet、IP-Adapter、LoRA 的原理与取舍；
- 设计 FID/CLIPScore/人工评估的评测方案；
- 用 90 秒回答任意高频题，并接住两层追问；
- 拿出一套可白板推导的 DDPM 笔记 + 可讲清的条件控制方案。

## 2. 适合谁

- 准备算法岗、AIGC 岗、多模态生成岗面试的同学；
- 做过 SD 应用，但理论不成体系的工程师；
- 会调包，但被问“为什么”容易卡住的同学；
- 想从 GAN/CV 传统方向转到生成式模型的同学；
- 需要一套课程/分享材料的技术负责人。

**先修要求**：

- Python + PyTorch 基础；
- 概率论（高斯、条件概率、KL）；
- 线性代数（矩阵乘法、特征值直觉）；
- 深度学习基础（CNN、Transformer、损失函数）。

不要求你已经会 Diffusion；第 1 章从零开始。

---

## 3. 课程设计原则

1. **问题驱动**：每节课从一个面试问题或工程问题开始，不堆知识点。
2. **三层递进**：公式 → 架构 → 工程，先懂“为什么”，再学“怎么用”。
3. **输出倒逼**：每节课都有练习/验收，每章都有产出。
4. **可检查**：每个练习都有交付物和验收标准，不靠“看过”代替掌握。
5. **面试导向**：每节课都标注对应面试题，最后做 90 秒回答和模拟面试。
6. **诚实呈现**：方案/练习报告要写失败与局限，面试官更看重思考过程。

## 5. 每节课怎么上（60–90 分钟）

| 环节 | 时间 | 做什么 |
|---|---|---|
| 回忆/自测 | 5 min | 用 3 个问题检查上节课 |
| 概念讲解 | 20–25 min | 讲“为什么”，板书公式/架构 |
| 白板/手算 | 20 min | 手推公式或做数值例子 |
| 面试问答 | 15 min | 90 秒回答 + 2 层追问 |
| 小结/作业 | 5–10 min | 复述、布置产出、验收标准 |

**课前**：读对应题库题 + 预习关键词。  
**课中**：必须动手写/画，不只看。  
**课后**：提交一个可检查的产出（一页纸、图、300 字、录音）。

## 7. 评估方式

| 模块 | 权重 | 说明 |
|---|---|---|
| 日常自测 | 20% | 每节课 3 个问题 + 90 秒复述 |
